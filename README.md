# Anniversary Gift

A responsive, single-page anniversary experience built with plain HTML, CSS and JavaScript. It can be hosted on GitHub Pages without a build step.

## Quick edits

- **`gift-config.js`**: edit all ordinary visible website text, names, dates, messages, story captions, location, and photo paths. Fixed interface labels are grouped under `ui`.
- **`assets/images/`**: store your Canva-edited photos and graphics here.
- **`index.html`**: layout, styling, and interaction code. You should rarely need to edit this file for text changes.

## Preview locally

Run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## GitHub Pages

Upload the contents of this folder to the repository root. In repository Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
